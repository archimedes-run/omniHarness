## Decisions (2026-10-19, owner)

**Phase 1 scope.** Brief items a–g, plus: policy on by default and failing closed (a build failure refuses tool calls, never runs them ungated); target drift checked on both routes; channel-boundary redaction, fail-closed; no synchronous self-HTTP on the event loop; the busy check (T-5); a failed run resolves FAILED with its reason and an explicit retry rule (T-8); cron catch-up fires once, late, with a note (T-11); session-watcher becomes a runtime dependency (W-1).

**Calendar.** Rejected at load with an error naming the missing calendar feed, surfaced in engine status; stale `models.py` comment fixed. Completion: registered, or rejected the same way.

**Order.** (a) an Article XI integration test through `build_loop` with production's arguments, committed xfail; (b) safety; (c) sources; (d) remote delivery last; (e) policy; (f) small fixes. Every wiring fix is sabotage-checked. Phase 1 ends with a manual Telegram end-to-end check on the running stack.

**Carried forward** (into ROADMAP-FOLLOWUPS): subagent `delegation_chain` provenance (P-5); unreachable UNKNOWN watcher state (W-2); the `OPENAI_API_KEY` e2e test hygiene failure (§3). `Outcome.SUPERSEDED` stays in Phase 2 as T090e.
